# Architecture Decision Records

Short records of the decisions worth defending in a review — the context, the
choice, the alternative rejected, and the consequences accepted. Format is a
lightweight [MADR](https://adr.github.io/madr/) variant.

| ADR | Decision | Status |
| --- | -------- | ------ |
| [0001](0001-enforced-nx-library-boundaries.md) | Enforced Nx library boundaries (one lib per layer per scope) | Accepted |
| [0002](0002-angular-zoneless-signal-first.md) | Angular zoneless + signal-first change detection | Accepted |
| [0003](0003-sse-live-only-no-replay.md) | SSE is live-only (no server-side replay buffer) | Accepted |
| [0004](0004-single-global-api-prefix.md) | Serve the whole API under a single global `/api` prefix | Accepted |
